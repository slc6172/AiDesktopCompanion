# AI 動畫朋友

[English summary](README.en.md)

一個住在你桌面上的 AI 陪伴角色。角色是一個**無邊框、真透明、可置頂**的桌寵視窗:用**真人照片風格**的全身動畫呈現,你可以打字、也可以直接開口跟它聊天;它會記得你說過的事,有自己的情緒、好感度,還能換衣服、拍照給你看。

> **僅支援 Windows 10 / 11。** 目前不支援 macOS 與 Linux。介面與角色語言為繁體中文。

## 特色

- **真人照片風格的全身動畫。** 你用自己準備的影片(專案不附任何角色):待機、聆聽、思考,以及五種情緒的說話動畫,會依對話狀態自動切換。做法見 [動畫製作教學](docs/animation-tutorial.md)。還沒有動畫也能用,角色會先以表情符號代替。
- **指令換裝。** 直接對角色說「換成睡衣」就會換上對應的那一套(每套服裝是 `clips` 裡的一個資料夾),重新啟動後仍是那一套。
- **可以自拍。**(選用)角色可以拍照給你看;每套服裝放一張基底照,拍出來的人物就會保持一致。
- **語音對話。** 按住說話(或按住 F2),或開啟「持續聆聽」直接開口,隨時可以打斷角色。聲音預設用免費的 Edge 語音,可換成男聲,也可接本機的語音伺服器或 Fish Audio。沒有麥克風或沒有語音辨識金鑰時,仍然可以打字。
- **記憶系統。** 對話只存在你的電腦上。聊過一段時間後,舊對話會被整理成日誌與長期事實(關於你的事、共同經歷、角色自己的事、待跟進的事),聊到相關話題時自動想起。
- **物品系統。** 角色記得自己在哪裡、身上的狀態(例如喝了酒、感冒了,過一陣子會自己恢復),以及持有的物品:得到或失去東西,都會在對話中被記下來。
- **好感度與情緒。** 角色每一句話都帶情緒,同時驅動動畫(和選用的 Fish 語音)。好感度是 0 到 100 的數值,會隨你們的互動升降;很久沒互動,它會慢慢回到「普通熟識」。
- **其他。** 知道現在幾點、跟你上一句話隔了多久(早午晚餐與深夜會有自然的反應);可以讓角色偶爾主動開口(預設關);可以讓角色上網查資料(選用);也可以把圖片丟給角色看。
- **角色由你定義。** 名字、個性、口吻、性別與代名詞都寫在你自己的人設檔裡,程式不預設任何一種。

## 需求

| 項目 | 說明 |
|---|---|
| 作業系統 | Windows 10 或 11(僅此) |
| Python | 3.11 或更新 |
| Node.js | 22.12 或更新。只用來**安裝**桌寵視窗(Electron),安裝好之後平常啟動不再需要 |

## 快速開始

在專案資料夾開啟 PowerShell(完整說明、Electron 下載慢時的鏡像與手動下載方法,見 [安裝教學](docs/install.md)):

```powershell
python -m venv .venv                                       # 1. 建立虛擬環境
.venv\Scripts\python -m pip install -r requirements.txt    # 2. 安裝套件(只裝進 .venv)
cd electron; npm install; cd ..                            # 3. 安裝桌寵視窗(Electron),只做一次
.venv\Scripts\python app.py --set-key                      # 4. 貼上 Gemini 金鑰(存進 Windows 憑證管理員)
copy persona.example.md persona.md                         # 5. 建立你自己的人設檔,再用記事本改成你想要的角色
.\run.bat                                                  # 6. 啟動
```

想用語音輸入的話,再執行一次 `.venv\Scripts\python app.py --set-key-groq` 存入 Groq 金鑰。

沒有金鑰、只想先看看畫面:完成第 1、2、3、5 步後,依 [設定參考](docs/configuration.md) 的 `COMPANION_FAKE` 說明進入離線試玩(假回覆、不花額度、不寫入你的紀錄)。

## 啟動與退出

- **啟動:** 雙擊 `run.bat`。它會先檢查安裝是否完整,然後**只**開出桌寵視窗(沒有命令列視窗)。出了問題想看輸出,改雙擊 `run-debug.bat`,它會保留命令列視窗。
- **視窗操作:** 畫面平常只有角色和右下角一顆小 ⚙。滑過或點它,工具列會向上展開:拖曳、置頂、穿透、縮放、對話面板。對話面板裡有輸入框、「🎤 按住說話」與「🎙️ 持續聆聽」。
- **退出:** 工具列**最上方**的退出鈕,按一次會變紅並顯示「再按一次結束」,再按一次才真的結束;或在系統匣圖示按右鍵 →「結束程式」。

## 你可以自己改的東西

| 檔案 / 資料夾 | 用途 |
|---|---|
| `persona.md` | 你的角色人設(從 `persona.example.md` 複製;改完重新啟動)。這個檔案是你自己的,不會被 git 追蹤 |
| `config.json` | 語音、時間觀念、換裝、照片、記憶等設定(從 `config.example.json` 複製)。每一項見 [設定參考](docs/configuration.md) |
| `clips\` | 角色動畫,每套服裝一個子資料夾。專案不附內容,做法見 [動畫製作教學](docs/animation-tutorial.md) |
| `fillers\` | 角色思考時播放的短音(選用) |
| `data\` | 對話紀錄與記憶(`history.db`)、視窗位置(`window-state.json`)、記錄檔(`app.log`) |

想讓角色**忘記一切**:關閉程式後刪掉 `data\history.db`。

## 金鑰

| 服務 | 用途 | 必要嗎 |
|---|---|---|
| Google Gemini | 對話 | 必要 |
| Groq | 語音辨識 | 只有語音輸入需要 |
| Fish Audio | 另一種雲端語音 | 選用 |
| Cloudflare | 照片生成 | 選用 |
| TinyFish | 上網查資料 | 選用 |

金鑰存在 Windows 憑證管理員或環境變數,**不會寫進任何檔案**。查找順序與各旗標見 [設定參考](docs/configuration.md)。

## 隱私與費用

- **哪些東西會離開你的電腦:**
  - 你的文字訊息(以及你附上的圖片)會送給 **Google Gemini**。
  - 你說話的**錄音**會送給 **Groq** 做語音辨識,Gemini 只會收到辨識後的文字。
  - 要念出來的句子會送給微軟的 Edge 線上語音服務(預設的語音);如果你選了 Fish Audio,則改送給 Fish。
  - 如果你啟用了選用功能:拍照的描述與服裝基底照會送給 Cloudflare;查資料的關鍵字會送給 TinyFish。
  - 開啟持續聆聽時,麥克風持續收音,但偵測到你開口才會送出,不是每一刻都在傳送。
- **本機保存:** 對話與記憶只存在你電腦上的 `data\history.db`。
- **隱私提醒:** Gemini 的免費額度可能被 Google 用於改進產品,所以**不建議跟角色聊很私密的內容**。若在意,需改用付費層(以 Google 目前的條款為準)。
- **費用:** 各服務的免費額度與價格以它們的官方頁面為準。一般聊天每則訊息用一次 Gemini 請求,長期記憶的整理會偶爾多用一次。
- **動畫素材:** 角色動畫由你自己製作,請確認你有權使用所用的照片與影片(特別是真人的形象)。
