# clips

角色動畫放在這裡:**每一套服裝一個子資料夾**,資料夾名稱就是服裝名稱,裡面至少要有 `idle.webm`(待機)。專案不附任何角色內容,內容由你自己製作。

```
clips\
  日常\
    idle.webm
    thinking.webm
    talking-happy.webm
    ...
  睡衣\
    idle.webm
    ...
```

檔名、可用的狀態、缺檔時的退回順序、自拍用的基底照,以及怎麼做出這些影片,全部寫在 [動畫製作教學](../docs/animation-tutorial.md)。資料夾名稱開頭是底線(例如 `_草稿`)的會被忽略。
